# ControlEvent v23_prod_r4

Cambios de esta versión:

- En **AVANCE DEL EVENTO**, **ASISTENCIA** aparece en primer lugar.
- **CONTROL DE HITOS** aparece en segundo lugar, con número de Hitos, LG cumplidas, LG pendientes y porcentaje de avance.
- Después se muestran INGRESOS, JUSTIFICANTES, DONACIONES, COMPRAS y DOCUMENTOS.
- Se oculta el texto de versión del encabezado superior derecho, manteniendo el icono CE y el reloj.
- La información de Hitos se consulta para el evento seleccionado y se actualiza al abrir la ficha.
