# ControlEvent v23_prod_r6 · Zuzu personalizada e HITOS en INFOEVENTO

Cambios incluidos:

- Al abrir «Zuzu, pregúntame lo que quieras», aparece una presentación personalizada con el identificador/apodo del usuario conectado.
- Durante la presentación el texto no se puede modificar. Zuzu intenta leerlo automáticamente y [Leer] permite repetirlo.
- Al terminar la locución o pulsar la escobita, el campo queda limpio y disponible para escribir o dictar.
- Las respuestas terminan con «[usuario], soy tu amigo Zuzu, pregúntame lo que quieras».
- INFOEVENTO incorpora como primera hoja `HITOS`, con resumen de Hitos, detalle completo de LG, responsables, fechas, estados, notas y dependencias previas/posteriores.
- Versión actualizada a `v23_prod_r6`.
